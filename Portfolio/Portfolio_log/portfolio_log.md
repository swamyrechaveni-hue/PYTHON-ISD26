# Portfolio Log

## Week 1

In Week 1, I was introduced to Python programming. I learned how to create and run Python scripts using Visual Studio Code.

I worked with variables, data types, casting, and arithmetic operations. I also explored string manipulation and f-strings.

Additionally, I developed a temperature converter program which takes user input and converts Celsius into Fahrenheit and Kelvin.

This week helped me build a strong foundation in Python programming.

## Week 2

In Week 2, I extended my Python knowledge by working with conditionals, loops, and lists.

I implemented comparison and logical operators to control program flow using if, if-else, and if-elif-else statements. I also created and modified lists and used loops such as for and while to iterate through data.

Additionally, I worked with user input and updated programs to make them interactive.

This week improved my understanding of program logic and control structures.

## Week 3

In Week 3, I learned how to create and use functions in Python, including parameters, return values, and default arguments.

I also explored variable scope and understood the difference between local and global variables. Additionally, I practiced identifying and fixing common errors such as syntax, name, value, and index errors.

Finally, I developed a to-do list application that integrates functions, loops, conditionals, and user input.

This week improved my ability to structure programs and debug code effectively.

## Week 4

In Week 4, I learned object-oriented programming concepts including classes, objects, and methods.

I developed a task management system using Task and TaskList classes and implemented features such as adding, removing, and updating tasks. I also used the datetime library to manage task dates.

Additionally, I modularized the program into multiple files to improve structure and maintainability.

This week improved my understanding of structured programming and modular design.

## Week 5

In Week 5, I focused on testing and basic GUI development.

I implemented automated tests using pytest for different programs and learned how to validate program correctness using assertions. I also developed a simple graphical interface using tkinter to manage tasks.

This week improved my understanding of testing practices and introduced GUI programming.

## Week 6

In Week 6, I learned inheritance and polymorphism in Python by creating class hierarchies such as Vehicle, Car, and Plane.

I also implemented multiple inheritance and method overriding. Additionally, I extended the ToDoApp by introducing a RecurringTask class and improved encapsulation by controlling access to tasks.

This week improved my understanding of object-oriented design and code reuse.

## Week 7

In Week 7, I implemented debugging, properties, and persistence.

I fixed logical errors using debugging techniques and introduced the @property decorator to improve data access. I also implemented persistence using CSV files and the DAO pattern to store and retrieve tasks.

This week improved my understanding of debugging and data persistence.

## Week 8

In Week 8, I refactored the ToDo application to follow SOLID principles and separation of concerns.

I separated the user interface, business logic, and data handling into different modules. I also implemented exception handling to ensure the program does not crash on invalid input.

This week improved my understanding of software design and code structure.

## Week 9

In Week 9, I worked with data structures such as tuples, sets, and dictionaries and implemented a histogram function.

I also learned about abstract classes and implemented dice simulations using inheritance.

Additionally, I extended the ToDo application by adding a PriorityTask class and integrating it into the system.

This improved my understanding of abstraction and extensibility in software design.
